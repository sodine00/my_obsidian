# Регулярные выражения Python

---

Регулярное выражение (RegEx) — это последовательность символов, образующая шаблон поиска.

Регулярные выражения можно использовать для проверки того, содержит ли строка указанный шаблон поиска.

---

## Модуль регулярных выражений

В Python есть встроенный пакет `re`, который можно использовать для работы с регулярными выражениями.

Импортируйте `re`модуль:

import re

---

## Регулярные выражения в Python

После импорта `re`модуля вы можете начать использовать регулярные выражения:

### Пример

Проверьте, начинается ли строка с "The" и заканчивается ли "Spain":

import re  
  
txt = "The rain in Spain"  
x = re.search("^The.*Spain$", txt)

---

## Функции регулярных выражений

Модуль `re`предоставляет набор функций, позволяющих искать совпадение в строке:

|Function|Description|
|---|---|
|[findall](https://www.w3schools.com/python/python_regex.asp#findall)|Returns a list containing all matches|
|[search](https://www.w3schools.com/python/python_regex.asp#search)|Returns a [Match object](https://www.w3schools.com/python/python_regex.asp#matchobject) if there is a match anywhere in the string|
|[split](https://www.w3schools.com/python/python_regex.asp#split)|Returns a list where the string has been split at each match|
|[sub](https://www.w3schools.com/python/python_regex.asp#sub)|Replaces one or many matches with a string|

## Специальные последовательности

Специальная последовательность — это последовательность, `\`за которой следует один из символов из приведенного ниже списка, и она имеет особое значение:

|Character|Description|Example|Try it|
|---|---|---|---|
|\A|Returns a match if the specified characters are at the beginning of the string|"\AThe"||
|\b|Returns a match where the specified characters are at the beginning or at the end of a word  <br>(the "r" in the beginning is making sure that the string is being treated as a "raw string")|r"\bain"  <br>  <br>r"ain\b"||
|\B|Returns a match where the specified characters are present, but NOT at the beginning (or at the end) of a word  <br>(the "r" in the beginning is making sure that the string is being treated as a "raw string")|r"\Bain"  <br>  <br>r"ain\B"||
|\d|Returns a match where the string contains digits (numbers from 0-9)|"\d"||
|\D|Returns a match where the string DOES NOT contain digits|"\D"||
|\s|Returns a match where the string contains a white space character|"\s"||
|\S|Returns a match where the string DOES NOT contain a white space character|"\S"||
|\w|Returns a match where the string contains any word characters (characters from a to Z, digits from 0-9, and the underscore _ character)|"\w"||
|\W|Returns a match where the string DOES NOT contain any word characters|"\W"||
|\Z|Returns a match if the specified characters are at the end of the string|"Spain\Z"||

## Наборы

Множество — это набор символов, заключенных в квадратные скобки `[]`и имеющих особое значение:

|Set|Description|Try it|
|---|---|---|
|[arn]|Returns a match where one of the specified characters (`a`, `r`, or `n`) is present||
|[a-n]|Returns a match for any lower case character, alphabetically between `a` and `n`||
|[^arn]|Returns a match for any character EXCEPT `a`, `r`, and `n`||
|[0123]|Returns a match where any of the specified digits (`0`, `1`, `2`, or `3`) are present||
|[0-9]|Returns a match for any digit between `0` and `9`||
|[0-5][0-9]|Returns a match for any two-digit numbers from `00` and `59`||
|[a-zA-Z]|Returns a match for any character alphabetically between `a` and `z`, lower case OR upper case||
|[+]|In sets, `+`, `*`, `.`, `\|`, `()`, `$`,`{}` has no special meaning, so `[+]` means: return a match for any `+` character in the string||

## Функция findall()

Функция `findall()`возвращает список, содержащий все совпадения.

### Пример

Вывести список всех совпадений:

import re  
  
txt = "The rain in Spain"  
x = re.findall("ai", txt)  
print(x)

В списке представлены совпадения в порядке их обнаружения.

Если совпадений не найдено, возвращается пустой список:

### Пример

Если совпадение не найдено, возвращается пустой список.

import re  
  
txt = "The rain in Spain"  
x = re.findall("Portugal", txt)  
print(x)

## Функция search()

Функция `search()`выполняет поиск совпадения в строке и возвращает [объект Match](https://www.w3schools.com/python/python_regex.asp#matchobject) , если совпадение найдено.

Если совпадений несколько, будет возвращено только первое из них:

### Пример

Найдите первый пробел в строке:

import re  
  
txt = "The rain in Spain"  
x = re.search("\s", txt)  
  
print("The first white-space character is located in position:", x.start())

`[None]Если совпадений не найдено, возвращается значение :

---

### Пример

Выполните поиск, который не даст результатов:

import re  
  
txt = "The rain in Spain"  
x = re.search("Portugal", txt)  
print(x)

---

 

## Функция split()

Функция `split()`возвращает список, в котором строка была разделена по каждому совпадению:

### Пример

Разделение по каждому пробельному символу:

import re  
  
txt = "The rain in Spain"  
x = re.split("\s", txt)  
print(x)

Количество повторений можно контролировать, указав следующий `maxsplit` параметр:

### Пример

Разделять строку только по первому вхождению:

import re  
  
txt = "The rain in Spain"  
x = re.split("\s", txt, 1)  
print(x)

---

 

## Функция sub()

Функция `sub()`заменяет найденные совпадения текстом по вашему выбору:

### Пример

Замените каждый пробел цифрой 9:

import re  
  
txt = "The rain in Spain"  
x = re.sub("\s", "9", txt)  
print(x)

Количество замен можно контролировать, указав следующий `count` параметр:

### Пример

Замените первые 2 вхождения:

import re  
  
txt = "The rain in Spain"  
x = re.sub("\s", "9", txt, 2)  
print(x)

## Сопоставление объекта

Объект Match — это объект, содержащий информацию о поиске и его результате.

**Примечание:**`[None] Если совпадение не найдено, будет возвращено значение , а не объект Match.

### Пример

Выполните поиск, который вернет объект Match:

import re  
  
txt = "The rain in Spain"  
x = re.search("ai", txt)  
print(x) #this will print an object

Объект Match имеет свойства и методы, используемые для получения информации о поисковом запросе и его результате:

`.span()`Возвращает кортеж, содержащий начальную и конечную позиции совпадения.  
`.string`Возвращает строку, переданную в функцию.  
`.group()`Возвращает часть строки, где было найдено совпадение.  

### Пример

Выведите позицию (начальную и конечную) первого совпадения.

Регулярное выражение ищет любые слова, начинающиеся с заглавной буквы "S":

import re  
  
txt = "The rain in Spain"  
x = re.search(r"\bS\w+", txt)  
print(**x.span()**)

### Пример

Выведите строку, переданную в функцию:

import re  
  
txt = "The rain in Spain"  
x = re.search(r"\bS\w+", txt)  
print(**x.string**)

### Пример

Выведите ту часть строки, где было найдено совпадение.

Регулярное выражение ищет любые слова, начинающиеся с заглавной буквы "S":

import re  
  
txt = "The rain in Spain"  
x = re.search(r"\bS\w+", txt)  
print(**x.group()**)

**Примечание:**`[None]` Если совпадение не найдено, будет возвращено значение , а не объект Match.
