## Что такое модуль?

Рассматривайте модуль как библиотеку кода.

Файл, содержащий набор функций, которые вы хотите включить в свое приложение.

## Создать модуль

Для создания модуля просто сохраните нужный код в файле с расширением `.py`:

### Пример
Сохраните этот код в файле с именем`mymodule.py`

def greeting(name):  
  print("Hello, " + name)

## Используйте модуль

Теперь мы можем использовать только что созданный модуль, применив следующую import инструкцию:

### Пример

Импортируйте модуль с именем mymodule и вызовите функцию greeting:

import mymodule  
  
mymodule.greeting("Jonathan")

**Примечание:** При использовании функции из модуля используйте следующий синтаксис: _module_name.function_name_ .

## Переменные в модуле

Модуль может содержать функции, как уже было описано, а также переменные всех типов (массивы, словари, объекты и т. д.):

### Пример

Сохраните этот код в файле.`mymodule.py`

person1 = {  
  "name": "John",  
  "age": 36,  
  "country": "Norway"  
}

### Пример

Импортируйте модуль с именем mymodule и получите доступ к словарю person1:

import mymodule  
  
a = mymodule.person1["age"]  
print(a)

## Наименование модуля

Вы можете назвать файл модуля как угодно, но он обязательно должен иметь расширение файла. `.py`

## Переименование модуля

При импорте модуля можно создать псевдоним, используя as ключевое слово:

### Пример

Создайте псевдоним `mymodule`для `mx`:

import mymodule as mx  
  
a = mx.person1["age"]  
print(a)

## Встроенные модули

В Python есть несколько встроенных модулей, которые вы можете импортировать в любое удобное для вас время.

### Пример

Импортируйте и используйте `platform`модуль:

import platform  
  
x = platform.system()  
print(x)

## Использование функции dir()

Встроенная функция позволяет вывести список всех имен функций (или имен переменных) в модуле. Эта dir() функция:

### Пример

Перечислите все определенные имена, относящиеся к модулю платформы:

import platform  
  
x = dir(platform)  
print(x)

**Примечание:** Эта dir() функция может использоваться для _всех_ модулей, в том числе и для тех, которые вы создаёте самостоятельно.

## Импорт из модуля

Вы можете импортировать только части модуля, используя from ключевое слово.

### Пример

Указанный модуль `mymodule`содержит одну функцию и один словарь:

def greeting(name):  
  print("Hello, " + name)  
  
person1 = {  
  "name": "John",  
  "age": 36,  
  "country": "Norway"  
}  

### Пример

Импортируйте из модуля только словарь person1:

from mymodule import person1  
  
print (person1["age"])

**Примечание:** При импорте с использованием from  ключевого слова не используйте имя модуля при ссылке на элементы внутри модуля. Пример: `person1["age"]`, **а не** ~~`mymodule.person1["age"]`~~
