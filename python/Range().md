## Range Python

Встроенная `range()`функция возвращает неизменяемую последовательность чисел, обычно используемую для выполнения цикла определенное количество раз.

Этот набор чисел имеет свой собственный тип данных, называемый `range`.

**Примечание:** "Неизменяемый" означает, что его нельзя изменить после создания.

## Создание диапазонов

Функцию `range()`можно вызвать с 1, 2 или 3 аргументами, используя следующий синтаксис:

`range(_start_, _stop_, _step_)`

## Использование списков для отображения диапазонов

Объект Range — это тип данных, представляющий собой неизменяемую последовательность чисел, и он не может быть непосредственно отображен.

Поэтому диапазоны значений часто преобразуются в списки для отображения.
### Пример

Преобразование различных диапазонов в списки:

print(list(range(5)))  
print(list(range(1, 6)))  
print(list(range(5, 20, 3)))

## Диапазоны нарезки

Как и в случае с другими последовательностями, диапазоны можно разрезать для извлечения подпоследовательности.
### Пример

Извлечь подпоследовательность из заданного диапазона:

r = range(10)  
print(r[2])  
print(r[:3])

**Примечание:** Первая инструкция print возвращает значение по индексу 2, а вторая инструкция print возвращает новый объект диапазона от индекса 0 до 3.

## Тестирование членства

Стрелочные полигоны поддерживают проверку членства у `in`оператора.
### Пример

Проверьте, присутствуют ли числа 6 и 7 в заданном диапазоне:

r = range(0, 10, 2)  
print(6 in r)  
print(7 in r)

Возвращаемое значение определяется `True`, когда число присутствует в заданном диапазоне, и `False`когда оно отсутствует.
## Длина

Диапазоны поддерживают `len()`функцию получения количества элементов в диапазоне.
### Пример

Получить длину диапазона:

r = range(0, 10, 2)  
print(len(r))
