

## Что такое виртуальная среда?

Виртуальная **среда** в Python — это изолированная среда на вашем компьютере, где вы можете запускать и тестировать свои проекты на Python.

Это позволяет управлять зависимостями, специфичными для конкретного проекта, без вмешательства в другие проекты или в исходную установку Python.

Представьте себе виртуальную среду как отдельный контейнер для каждого проекта на Python. Каждый контейнер:

- Имеет собственный интерпретатор Python.
- Имеет собственный набор установленных пакетов.
- Изолирован от других виртуальных сред
- Могут существовать разные версии одного и того же пакета.

Использование виртуальных сред важно, потому что:

- Это предотвращает конфликты версий пакетов между проектами.
- Делает проекты более портативными и воспроизводимыми.
- Обеспечивает чистоту вашей системной установки Python.
- Позволяет проводить тестирование с различными версиями Python.

## Создание виртуальной среды

В Python есть встроенный `venv`модуль для создания виртуальных сред.

Чтобы создать виртуальную среду на вашем компьютере, откройте командную строку, перейдите в папку, где вы хотите создать свой проект, и введите следующую команду:

### Пример

Выполните эту команду, чтобы создать виртуальное окружение с именем `myfirstproject`:

Windows

macOS/Linux

C:\Users\_Your Name_> python -m venv myfirstproject

Это создаст виртуальное окружение и папку с именем "myfirstproject" с подпапками и файлами, примерно так:

### Результат

Структура файлов/папок будет выглядеть следующим образом:

myfirstproject  
  Include  
  Lib  
  Scripts  
  .gitignore  
  pyvenv.cfg

## Активировать виртуальную среду

Для использования виртуальной среды необходимо активировать её с помощью следующей команды:

### Пример

Активируйте виртуальную среду:

Windows

macOS/Linux

$ source myfirstproject/bin/activate

После активации ваше приглашение командной строки изменится, показывая, что вы теперь работаете в активной среде:

### Результат

При активации виртуальной среды командная строка будет выглядеть следующим образом:

Windows

macOS/Linux

(myfirstproject) C:\Users\_Your Name_>

## Установить пакеты

После активации виртуальной среды вы можете устанавливать в неё пакеты, используя команду pip
Мы установим пакет под названием 'cowsay':

### Пример

Установите 'cowsay' в виртуальную среду:

Windows

macOS/Linux

(myfirstproject) C:\Users\_Your Name_> pip install cowsay

### Результат

Пакет 'cowsay' устанавливается только в виртуальной среде:

## Использование пакета

Теперь, когда модуль 'cowsay' установлен в вашей виртуальной среде, давайте используем его для отображения говорящей коровы.

Создайте на своем компьютере файл с таким же названием `test.py`. Вы можете разместить его где угодно, но я размещу его в том же месте, что и `myfirstproject`папка — не _внутри_ папки, а в том же самом месте.

Откройте файл и вставьте в него следующие три строки:

### Пример

Вставьте две строки в `test.py`:

тест.py

import cowsay  
  
cowsay.cow("Good Mooooorning!")  

Затем попробуйте выполнить файл, находясь в виртуальной среде:

### Пример

Выполнить `test.py`в виртуальной среде:

Windows

macOS/Linux

(myfirstproject) C:\Users\_Your Name_> python test.py

В результате в вашем терминале появится изображение коровы:

### Результат

Цель модуля «корова говорит» — нарисовать корову, которая произносит любое введенное вами слово:

  _________________
| Good Mooooorning! |
  =================
                 \
                  \
                    ^__^
                    (oo)\_______
                    (__)\       )\/\
                        ||----w |
                        ||     ||

## Отключить виртуальную среду

Для деактивации виртуальной среды используйте следующую команду:

### Пример

Отключите виртуальную среду:

Windows

macOS/Linux

(myfirstproject) C:\Users\_Your Name_> deactivate

В результате вы снова оказались в обычном интерфейсе командной строки:

### Результат

Обычный интерфейс командной строки:

Windows

macOS/Linux

C:\Users\_Your Name_>

Если вы попытаетесь запустить `test.py`файл вне виртуальной среды, вы получите ошибку, поскольку отсутствует компонент 'cowsay'. Он был установлен только в виртуальной среде:

### Пример

Выполнение `test.py`вне виртуальной среды:

Windows

macOS/Linux

C:\Users\_Your Name_> python test.py

### Результат

Ошибка, так как отсутствует слово 'cowsay':

Traceback (most recent call last):  
  File "C:\Users\_Your Name_\test.py", line 1, in <module>  
    import cowsay  
ModuleNotFoundError: No module named 'cowsay'

**Примечание:** Виртуальная среда `myfirstproject`по-прежнему существует, она просто не активирована. Если вы снова активируете виртуальную среду, вы сможете запустить файл `test.py` , и диаграмма отобразится.

## Удалить виртуальную среду

Ещё одно преимущество работы с виртуальной средой заключается в том, что если по какой-либо причине вы захотите её удалить, от неё не будут зависеть другие проекты, и будут удалены только модули и файлы в указанной виртуальной среде.

Чтобы удалить виртуальное окружение, вы можете просто удалить его папку со всем содержимым. Это можно сделать либо непосредственно в файловой системе, либо с помощью командной строки следующим образом:

### Пример

Удалить `myfirstproject`из командной строки:

Windows

macOS/Linux

C:\Users\_Your Name_> rmdir /s /q myfirstproject
