## Итераторы Python

Итератор — это объект, содержащий счетное количество значений.

Итератор — это объект, по которому можно итерировать, то есть можно пройтись по всем значениям.

Технически, в Python итератор — это объект, реализующий протокол итераторов, который состоит из методов `__iter__()` и `__next__()`.

---

## Итератор против итерируемого объекта

Списки, кортежи, словари и множества — все это итерируемые объекты. Они представляют собой итерируемые _контейнеры_ , из которых можно получить итератор.

Все эти объекты имеют `iter()`метод, который используется для получения итератора:

### Пример
Возвращает итератор из кортежа и выводит каждое значение:

mytuple = ("apple", "banana", "cherry")  
myit = iter(mytuple)  
  
print(next(myit))  
print(next(myit))  
print(next(myit))  

Даже строки являются итерируемыми объектами и могут возвращать итератор:

### Пример

Строки также являются итерируемыми объектами, содержащими последовательность символов:

mystr = "banana"  
myit = iter(mystr)  
  
print(next(myit))  
print(next(myit))  
print(next(myit))  
print(next(myit))  
print(next(myit))  
print(next(myit))

## Циклическая обработка итератора

`[for](https://www.w3schools.com/python/ref_keyword_for.asp)`Для перебора итерируемого объекта можно также использовать цикл:

### Пример

Переберите значения кортежа:

mytuple = ("apple", "banana", "cherry")  
  
for x in mytuple:  
  print(x)

### Пример

Переберите символы строки:

mystr = "banana"  
  
for x in mystr:  
  print(x)

Фактически, цикл for создает объект-итератор и выполняет next() (https://www.w3schools.com/python/ref_func_next.asp)` метод для каждого элемента цикла.

## Создайте итератор

Для создания объекта/класса в качестве итератора необходимо реализовать соответствующие методы `__iter__()`для `__next__()`вашего объекта.

Как вы узнаете из главы [«Классы/Объекты Python»](https://www.w3schools.com/python/python_classes.asp) , у всех классов есть функция с именем ` `__init__()`.`, которая позволяет выполнить некоторую инициализацию при создании объекта.

Этот `__iter__()`метод работает аналогично: вы можете выполнять операции (инициализацию и т. д.), но он всегда должен возвращать сам объект итератора.

Этот `__next__()`метод также позволяет выполнять операции и должен возвращать следующий элемент в последовательности.

### Пример

Создайте итератор, который возвращает числа, начиная с 1, причем каждая последующая последовательность будет увеличиваться на единицу (возвращая 1, 2, 3, 4, 5 и т. д.):

class MyNumbers:  
  def __iter__(self):  
    self.a = 1  
    return self  
  
  def __next__(self):  
    x = self.a  
    self.a += 1  
    return x  
  
myclass = MyNumbers()  
myiter = iter(myclass)  
  
print(next(myiter))  
print(next(myiter))  
print(next(myiter))  
print(next(myiter))  
print(next(myiter))

## СтопИтерация

Приведенный выше пример будет продолжаться бесконечно, если у вас будет достаточно операторов next() или если он будет использоваться в for цикле.

Чтобы предотвратить бесконечное продолжение итерации, мы можем использовать `StopIteration`следующее выражение.

В `__next__()`метод можно добавить условие завершения, чтобы вызвать ошибку, если итерация будет выполнена указанное количество раз:

### Пример

Остановить после 20 итераций:

class MyNumbers:  
  def __iter__(self):  
    self.a = 1  
    return self  
  
  def __next__(self):  
    if self.a <= 20:  
      x = self.a  
      self.a += 1  
      return x  
    else:  
      raise StopIteration  
  
myclass = MyNumbers()  
myiter = iter(myclass)  
  
for x in myiter:  
  print(x)
