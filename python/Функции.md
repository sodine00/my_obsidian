Функция — это блок кода, который выполняется только при вызове.
Функция может возвращать данные в качестве результата.
Функция помогает избежать повторения кода.

Информацию можно передавать в функции в качестве аргументов.
Аргументы указываются после имени функции, внутри скобок. Вы можете добавить любое количество аргументов, просто разделяйте их запятой.
Параметром является переменная **,** указанная в скобках в определении функции.
Аргументом является фактическое значение **,** передаваемое функции при её вызове.

Аргументы можно передавать с помощью синтаксиса _"ключ_ = _значение"_ .
my_function(animal = "dog", name = "Buddy")

Когда вы вызываете функцию с аргументами без использования ключевых слов, они называются позиционными аргументами.
Позиционные аргументы должны быть расположены в правильном порядке:
my_function("dog", "Buddy")

## Произвольные аргументы - *args
Если вы не знаете, сколько аргументов будет передано в вашу функцию, добавьте символ "a" `*`перед именем параметра.
Таким образом, функция получит _кортеж_ аргументов и сможет получить доступ к элементам соответствующим образом:

def my_function(***kids**):  
  print("The youngest child is " + kids[2])  
  
my_function("Emil", "Tobias", "Linus")

## Произвольные аргументы ключевых слов - **kwargs
Если вы не знаете, сколько именованных аргументов будет передано в вашу функцию, добавьте две звездочки `**`перед именем параметра.
Таким образом, функция получит _словарь_ аргументов и сможет получить доступ к элементам соответствующим образом:

def my_function(****kid**):  
  print("His last name is " + kid["lname"])  
  
my_function(fname = "Tobias", lname = "Refsnes")

Этот `**kwargs`параметр позволяет функции принимать любое количество именованных аргументов.
Внутри функции `kwargs`это становится словарем, содержащим все именованные аргументы
### Пример

def my_function(username, **details):  
  print("Username:", username)  
  print("Additional details:")  
  for key, value in details.items():  
    print(" ", key + ":", value)  
my_function("emil123", age = 25, city = "Oslo", hobby = "coding")


## Разбор аргументов
Операторы ` `*`and` `**`также могут использоваться при _вызове_ функций для распаковки (расширения) списка или словаря в отдельные аргументы.
### Распаковка списков со знаком *
Если у вас есть значения, хранящиеся в списке, вы можете использовать `*`его для распаковки в отдельные аргументы
### Распаковка словарей с помощью **
Если у вас есть именованные аргументы, хранящиеся в словаре, вы можете использовать `**`их для распаковки

## Глобальное ключевое слово
Если вам нужно создать глобальную переменную, но вы ограничены локальной областью видимости, вы можете использовать `[global](https://www.w3schools.com/python/ref_keyword_global.asp)`ключевое слово.
Это **global** ключевое слово делает переменную глобальной.

## Нелокальное ключевое слово
Это `nonlocal`ключевое слово используется для работы с переменными внутри вложенных функций.
Это `nonlocal`ключевое слово привязывает переменную к внешней функции.
Если вы используете `nonlocal`ключевое слово, переменная будет принадлежать внешней функции

# Декораторы Python

Декораторы позволяют добавлять дополнительное поведение к функции, не изменяя при этом код функции.
Декоратор — это функция, которая принимает другую функцию в качестве входных данных и возвращает новую функцию.

## Базовый декоратор
Сначала определите декоратор, а затем примените его с помощью `@decorator_name`функции, указанной выше.
Простой декоратор, который преобразует возвращаемое значение декорируемой функции в верхний регистр.

def changecase(func):  
  def myinner():  
    return func().upper()  
  return myinner  
  
@changecase  
def myfunction():  
  return "Hello Sally"  
  
print(myfunction())

Размещая `@changecase`функцию непосредственно над её определением, её `myfunction`как бы «украшают» этой `changecase` функцией.
Эта функция `changecase`является декоратором.
Функция `myfunction`— это функция, которая подвергается декорированию.
Декоратор можно вызывать несколько раз. Просто разместите декоратор над функцией, которую хотите украсить.

## Аргументы в декорированной функции

Функции, требующие аргументов, также могут быть помечены декораторами, просто убедитесь, что вы передаете аргументы функции-обертке:
### Пример
Функции с аргументами также могут быть помечены декораторами:

def changecase(func):  
  def myinner(x):  
    return func(x).upper()  
  return myinner  
  
@changecase  
def myfunction(nam):  
  return "Hello " + nam  
  
print(myfunction("John"))

декораторы могут принять свои собственные аргументы, добавив еще один уровень обертки.
def changecase(n):  
  def changecase(func):  
    def myinner():  
      if n == 1:  
        a = func().lower()  
      else:  
        a = func().upper()  
      return a  
    return myinner  
  return changecase  
  
@changecase(1)  
def myfunction():  
  return "Hello Linus"  
  
print(myfunction())

В одной функции можно использовать несколько декораторов.
Это достигается путем наложения вызовов декоратора друг на друга.
Декораторы вызываются в обратном порядке, начиная с того, который находится ближе всего к функции.

## Сохранение метаданных функций

Функции в Python содержат метаданные, доступ к которым осуществляется с помощью атрибутов `<function> `__name__`` и `<function> `__doc__``.
### Пример

Обычно имя функции можно вернуть с помощью `__name__`атрибута:

def myfunction():  
  return "Have a great day!"  
  
print(myfunction.`__name__`)

Однако, при добавлении декоратора к функции, метаданные исходной функции теряются.
### Пример
Попробуйте вернуть имя из функции, помеченной декоратором, и вы получите другой результат:

def changecase(func):  
  def myinner():  
    return func().upper()  
  return myinner  
  
@changecase  
def myfunction():  
  return "Have a great day!"  
  
print(myfunction.__name__)

Для решения этой проблемы в Python есть встроенная функция `functools.wraps`, которая позволяет сохранить исходное имя функции и строку документации.
### Пример
Импортируйте `functools.wraps`, чтобы сохранить исходное имя функции и строку документации.

import functools  
  
def changecase(func):  
  @functools.wraps(func)  
  def myinner():  
    return func().upper()  
  return myinner  
  
@changecase  
def myfunction():  
  return "Have a great day!"  
  
print(myfunction.__name__)

## Лямбда-функции

Лямбда-функция — это небольшая анонимная функция.

Лямбда-функция может принимать любое количество аргументов, но может содержать только одно выражение.

### Пример

Добавьте 10 к аргументу `a`и верните результат:

x = lambda a : a + 10  
print(x(5))

Лямбда-функции могут принимать любое количество аргументов:
### Пример

Умножьте аргумент `a`на аргумент `b`и верните результат:

x = lambda a, b : a * b  
print(x(5, 6))


Мощь лямбда-функций лучше всего проявляется при их использовании в качестве анонимной функции внутри другой функции.

Допустим, у вас есть определение функции, которая принимает один аргумент, и этот аргумент будет умножен на неизвестное число:

def myfunc(n):  
  return lambda a : a * n

Используйте это определение функции, чтобы создать функцию, которая всегда удваивает передаваемое вами число:
### Пример

def myfunc(n):  
  return lambda a : a * n  
  
mydoubler = myfunc(2)  
  
print(mydoubler(11))

Используйте лямбда-функции, когда анонимная функция необходима на короткий промежуток времени.

## Лямбда-функции со встроенными функциями
Лямбда-функции обычно используются со встроенными функциями, такими как `map()`, `filter()`, и `sorted()`.
### Использование лямбда-функций с функцией map()
Данная `map()`функция применяет другую функцию к каждому элементу итерируемого объекта:
### Пример
Удвойте все числа в списке:

numbers = [1, 2, 3, 4, 5]  
doubled = list(map(lambda x: x * 2, numbers))  
print(doubled)
