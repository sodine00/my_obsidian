В Python имеется набор встроенных математических функций, включая обширный модуль `math`, позволяющий выполнять математические операции над числами.

---

## Встроенные математические функции

Функции min() и max() можно использовать для поиска наименьшего или наибольшего значения в итерируемом объекте:

### Пример

x = min(5, 10, 25)  
y = max(5, 10, 25)  
  
print(x)  
print(y)

Функция abs() возвращает абсолютное (положительное) значение указанного числа:

### Пример

x = abs(-7.25)  
  
print(x)

Функция возвращает значение x, возведенное в степень y (x y ).`pow(_x_, _y_)`

### Пример

Верните значение 4 в степень 3 (то же самое, что 4 * 4 * 4):

x = pow(4, 3)  
  
print(x)

---

## Математический модуль

В Python также есть встроенный модуль `math`, который расширяет список математических функций.

Для его использования необходимо импортировать `math`модуль:

import math

После импорта `math`модуля вы можете начать использовать его методы и константы.

`math.sqrt()`Например, этот метод возвращает квадратный корень из числа:

### Пример

import math  
  
x = math.sqrt(64)  
  
print(x)

Данный `math.ceil()`метод округляет число в большую сторону до ближайшего целого числа, а также `math.floor()` в меньшую сторону до ближайшего целого числа и возвращает результат:

### Пример

import math  
  
x = math.ceil(1.4)  
y = math.floor(1.4)  
  
print(x) # returns 2  
print(y) # returns 1

Эта `math.pi`константа возвращает значение PI (3,14...):

### Пример

import math  
  
x = math.pi  
  
print(x)
