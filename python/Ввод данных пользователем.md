Python позволяет вводить данные пользователем.

Это означает, что мы можем запросить у пользователя ввод данных.

В следующем примере запрашивается ваше имя, и после ввода имени оно отображается на экране:

### Пример
Запросите мнение пользователя:

print("Enter your name:")  
name = input()  
print(f"Hello {name}")  

Выполнение кода в Python прекращается, когда доходит до нужной input() функции, и продолжается после того, как пользователь введёт необходимые данные.

---

## Используя подсказку

В приведенном выше примере пользователю нужно было ввести свое имя на новой строке. input() Функция Python имеет `prompt`параметр, который выступает в качестве сообщения, которое можно разместить перед введенным пользователем текстом на той же строке:

### Пример

Добавьте сообщение перед полем ввода пользователя:

name = input("Enter your name:")  
print(f"Hello {name}")  

---

## Множественные входы

Вы можете добавить столько полей ввода, сколько хотите, Python остановит выполнение на каждом из них, ожидая ввода от пользователя:

### Пример

Множественные входные данные:

name = input("Enter your name:")  
print(f"Hello {name}")  
fav1 = input("What is your favorite animal:")  
fav2 = input("What is your favorite color:")  
fav3 = input("What is your favorite number:")  
print(f"Do you want a {fav2} {fav1} with {fav3} legs?")  


---

## Введите число

Вводимые пользователем данные обрабатываются как строка. Даже если в приведенном выше примере вы введете число, интерпретатор Python все равно будет рассматривать его как строку.

Вы можете преобразовать входные данные в число с помощью следующей float() функции:

### Пример

Для нахождения квадратного корня входные данные необходимо преобразовать в число:

x = input("Enter a number:")  
  
#find the square root of the number:  
y = math.sqrt(float(x))  
  
print(f"The square root of {x} is {y}")  

---

## Проверка входных данных

Рекомендуется проверять правильность ввода данных пользователем. В приведенном выше примере ошибка возникнет, если пользователь введет что-либо, кроме числа.

Чтобы избежать ошибок, мы можем проверить ввод, и если это не число, пользователь может получить сообщение типа «Неверный ввод, пожалуйста, попробуйте еще раз», и ему будет разрешено ввести новое значение:

### Пример

Спрашивайте до тех пор, пока не получите номер:

y = True  
while y == True:  
  x = input("Enter a number:")  
  try:  
    x = float(x);  
    y = False  
  except:  
    print("Wrong input, please try again.")  
  
print("Thank you!")
