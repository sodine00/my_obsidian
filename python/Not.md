`None`В Python это специальная константа, обозначающая отсутствие значения.

Его тип данных — `NoneType`, и `None`это единственный экземпляр объекта `NoneType`.

---

## NoneType

Переменным можно присваивать значения `None`, указывающие на "отсутствие значения" или "не задано".

### Пример

Присвоить и отобразить `None`значение:

x = None  
print(x)

Используйте эту функцию `type()`, чтобы узнать тип значения `None`.

### Пример

Присвоить значение и вывести его тип `None`:

x = None  
print(type(x))

---

## По сравнению ни с кем

Для сравнения значения с `None`, используйте оператор тождества `is`или`is not`

### Пример

`is`Для сравнений с `None`: используйте оператор тождества

result = None  
if result is None:  
  print("No result yet")  
else:  
  print("Result is ready")

### Пример

Аналогичный пример, но с использованием `is not`вместо этого:

result = None  
if result is not None:  
  print("Result is ready")  
else:  
  print("No result yet")

## Функции, возвращающие None

Функции, которые явно не возвращают значение, возвращают значение `None`по умолчанию.

### Пример

Функция без оператора return возвращает `None`:

def myfunc():  
  x = 5  
  
x = myfunc()  
print(x)
